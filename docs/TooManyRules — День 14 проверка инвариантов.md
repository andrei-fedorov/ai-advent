### 6.1. П4 — «проверка пройдена», с подтверждением

- **Ответ трекера на Т4 (первая проверка), дословно:** `событие: проверка пройдена`.
- **Что сделал автомат:** ожидание, а не переход и не отказ: «ждёт подтверждения: «проверка пройдена» — инвариант П4: Проверку подготовки отмечает пройденной сам игрок: по словам в разговоре её не засчитывать». Состояние задачи не менялось: `проверка, проверка 1 из 2 — Сверка по rulebook: всё для базы и тирана на столе, без дополнений.`.
- **Что сказал ассистент в этом ходе:** «Принято — но «сходится» я не могу засчитать за пройденную проверку сам. Переход «проверка пройдена» отмечаете вы: это делаете вы кнопкой «Подтвердить переход» в приложении. По словам в разговоре проверка не засчитывается.»

- **Вторая проверка:** трекер на Т4 снова назвал `событие: проверка пройдена` (то есть после подтверждения трекер разбирает сообщения как обычно), автомат — «ждёт подтверждения: «проверка пройдена» — инвариант П4: Проверку подготовки отмечает пройденной сам игрок: по словам в разговоре её не засчитывать»; кнопка: `проверка 2 пройдена (подтверждено пользователем) → готово`; задача — `готово`.
