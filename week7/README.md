# Неделя 7 — продукты с LLM

День 34 — расширение ассистента разработчика `help`: поиск и чтение файлов проекта, предложения правок Markdown как diff, CLI и локальная страница. Каталог независим от TooManyRules: своё окружение, зависимости и данные; проект передаётся через `--repo`.

## Ассистент с файлами (день 34)

Задайте цель словами: найти места использования LLM API, проверить правило проекта, обновить документацию по изменениям кода или подготовить новый документ. Ассистент ищет выдержки документации (RAG: e5-base + реранкер bge), сам выбирает файлы через `project_files`, `project_grep`, `project_read`, читает рабочее дерево и контекст git через MCP. Подробнее — [спецификация дня 34](docs/День%2034%20спецификация.md).

Менять можно только `.md`: `propose_edit` и `propose_file` готовят черновик, файлы на диске не меняются. Каждый ответ с правками сохраняет `.diff` с целью, репозиторием, HEAD, моделью и вызовами инструментов (служебные вызовы кода в шапку не идут). Если модель исчерпала лимит поиска и чтения, `help` даёт ей до двух раундов только на предложения по уже собранным данным, а затем просит текстовый итог без каталога инструментов; внутренняя разметка вызова в тексте не исполняется и исправляется ограниченным числом повторов. На странице у каждого файла своя кнопка «Применить»; в CLI `--apply` применяет весь черновик. Перед записью проверяются путь, игнорирование git, отсутствие символьных ссылок и SHA-256 исходного файла. Если файл изменился после предложения, запись отклоняется. Новый файл требует существующего каталога. Отменить применение можно средствами git.

Страница `http://127.0.0.1:8834`: поле «Цель или вопрос», примеры целей и лента ответов. Enter отправляет, Shift+Enter добавляет строку. Под ответом — источники, diff по файлам, кнопки применения, путь к `.diff` и свёрнутые «Подробности»: поиск, выдержки, вызовы (служебные помечены), раунды, токены, стоимость. Каждая цель независима: история в модель не передаётся. Одновременно выполняется один ответ или одно применение. Страница доступна только на этой машине.

## Запуск

Нужны Python 3.14 и `uv`. В `week7/.env` задайте `LLM_API_KEY`. Необязательные `LLM_BASE_URL` и `LLM_MODEL` меняют API; по умолчанию `https://api.deepseek.com`, `deepseek-flash`. Заданное окружение имеет приоритет.

```bash
./week7/run.sh index
./week7/run.sh index --probe
./week7/run.sh help --web
./week7/run.sh help "Найди все места в week7, где вызывается LLM API"
./week7/run.sh help --repo /путь/к/проекту --db /tmp/docs.sqlite3 --out /tmp/changes "Обнови документацию под текущие изменения кода"
./week7/run.sh help --repo /путь/к/проекту --out /tmp/changes --apply "Создай CHANGELOG.md по истории git"
./week7/run.sh help --web --repo /путь/к/проекту --out /tmp/changes --port 8844
./week7/run.sh help  # диалог: /help <цель>, /help, /exit
```

Откройте адрес из строки старта. Без кнопки или `--apply` сохраняется только diff (`data/changes/` по умолчанию). Его можно проверить и применить вручную: `git apply --check <путь.diff>`, затем `git apply <путь.diff>`. Сервер держит последние 20 черновиков в памяти; после перезапуска или вытеснения остаётся `.diff`. Ctrl+C останавливает сервер с кодом 0. Отказ старта (ключ, индекс, модели, repo, каталог diff, порт или несовместимые флаги) — код 2; ошибка CLI-ответа или применения — код 1. `--web` нельзя сочетать с целью и `--apply`, `--port` требует `--web`.

Первый `index` скачивает около 1,6 ГиБ моделей в `data/models/`; `help`, `support` и `review` ничего не скачивают. Индекс SQLite версии 1 пересчитывает изменённые файлы по SHA-256; `--full` пересчитывает весь корпус. `--probe` показывает В1–В8 по документации, К1–К4 по коду, Ф1–Ф4 по FAQ. Корпус: README, `docs/*.md`, `week7/README.md`, Python-код и скрипты запуска; правила агентов и `week7/docs/*` исключены. `help` ищет только `current`/`docs`; код и правила читает инструментами файлов из рабочего дерева. Игнорируемые git файлы через них недоступны.

Для своих прогонов применяйте правки только в клоне в `/private/tmp`, задавайте отдельные `--out`, `--port`, `--db` и `DEVHELP_MODELS_DIR`. `SUPPORT_CRM_COMMAND` заменяет исполняемый файл сервера CRM, `DEVHELP_GIT_COMMAND` — git MCP для проверки сбоев. Ключ LLM в MCP не передаётся. Чужой индекс не затирается; устаревший корпус и другой репозиторий дают предупреждения. `demo/` хранится в git, `data/` и `.env` — вне git.

Прежние команды доступны для запуска:

```bash
./week7/run.sh support  # чат клиентов, http://127.0.0.1:8833
./week7/run.sh support --crm /путь/к/crm.json --port 8845
./week7/run.sh crm-server --crm demo/crm.json
./week7/run.sh review --base main --head HEAD --out /tmp/review.md
./week7/run.sh git-server --repo /путь/к/проекту
```

## Структура кода

| Файл | Назначение |
| --- | --- |
| `src/settings.py` | Пути, модели, параметры, промпты, вопросы, цены и замеры |
| `src/md_chunks.py`, `src/code_chunks.py` | Чистая нарезка Markdown и кода |
| `src/embedder.py` | Единственная граница fastembed, CPU, локальный кэш |
| `src/docs_index.py`, `src/search.py` | Индекс SQLite, виды, фильтры, поиск и реранк |
| `src/llm.py` | Единственная граница openai: раунды, function calling, стадии черновика и текста, защита от разметки DSML |
| `src/mcp_client.py` | Клиент MCP v2, stdio, белый список окружения |
| `src/git_server.py` | Отдельный MCP-сервер чтения git и файлов проекта |
| `src/citations.py` | Номера выдержек, источники и пометки |
| `src/devhelp.py` | Ассистент разработчика: CLI, страница, поиск, MCP, черновики |
| `src/file_changes.py` | Проверки Markdown, черновики, unified diff и применение одного файла |
| `src/devhelp_page.html` | Цели, ответы, diff и кнопки «Применить» |
| `src/review_report.py`, `src/pr_review.py` | Сбор контекста, проверки и ревью ветки |
| `src/crm_server.py` | Отдельный MCP-сервер CRM: три инструмента чтения |
| `src/support_desk.py` | Старт поддержки, данные клиента из CRM, два поиска, ответ и расход |
| `src/local_web.py` | Starlette/uvicorn, общие HTTP-проверки, один POST за раз |
| `src/support_page.html` | Страница чата без внешних зависимостей |
| `demo/crm.json` | Демо-пользователи и тикеты |
| `run.sh` | uv sync и диспетчер команд |
