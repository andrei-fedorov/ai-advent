# Неделя 7 — продукты с LLM

Небольшие продукты AI Advent Challenge живут здесь независимо от TooManyRules: своё окружение, зависимости и данные, проект передаётся через `--repo`.

## Ассистент поддержки (день 33)

`support` готовит черновик ответа пользователю по FAQ поддержки и документации (RAG: e5-base + реранкер bge), учитывая тикет и пользователя из JSON CRM через MCP. Оператор проверяет, редактирует и копирует ответ. Подробнее — [спецификация дня 33](docs/День%2033%20спецификация.md).

`demo/crm.json` содержит вымышленные данные: 4 пользователя и 10 тикетов. Сервер CRM отдаёт только данные для поддержки, без `contact`; записей и отправки сообщений нет. Тикет и пользователя запрашивает код, похожие обращения модель ищет сама. Без тикета получается общий ответ о продукте без подключения CRM. FAQ поддержки — документ демо-продукта `docs/TooManyRules — FAQ поддержки.md` в репозитории, заданном через `--repo`.

Страница `http://127.0.0.1:8833`: слева список и фильтр статуса; в центре тикет и свёрнутые данные пользователя; справа вопрос, редактируемый черновик, копирование, источники, строка CRM и расход. «Контекст ответа» показывает запрос поиска, все выдержки с оценками и вызовы инструментов. Новый ответ заменяет прежний; при ошибке прежний черновик остаётся. Одновременно готовится один ответ. Узкое окно складывает колонки вертикально.

Пример формы черновика (не результат реального прогона):

```text
По журналу аккаунта ключ вашего клиента перевыпущен, старый отозван.
На странице чата нажмите «Забыть ключ» и введите новый ключ от владельца [1].
```

Тот же вопрос об авторизации в другом тикете должен учитывать отсутствие `TOOMANYRULES_LOCAL_KEY` в приложении. Терминал показывает подключение MCP, инструменты и размеры ответов, отдельные поиски FAQ и документации, раунды модели, токены и стоимость. Полные тексты тикетов не логируются. Страница доступна только на этой машине; сетевого входа нет.

## Запуск

Нужны Python 3.14 и `uv`. В `week7/.env` задайте `LLM_API_KEY`. Необязательные `LLM_BASE_URL` и `LLM_MODEL` меняют API; по умолчанию `https://api.deepseek.com`, `deepseek-flash`. Заданное окружение имеет приоритет.

```bash
./week7/run.sh index
./week7/run.sh index --probe
./week7/run.sh support
./week7/run.sh support --repo /путь/к/проекту --db /tmp/support.sqlite3 --crm /путь/к/crm.json --port 8834
./week7/run.sh crm-server --crm demo/crm.json
```

Откройте в браузере адрес из строки старта. Пустое поле вопроса означает последнее сообщение пользователя в выбранном тикете. Для общего вопроса выберите «Без тикета». Ctrl+C останавливает сервер с кодом 0. Отказ старта (ключ, индекс, модели, CRM, порт) — код 2; ошибки отдельного запроса показываются на странице и не останавливают сервис.

Первый `index` скачивает около 1,6 ГиБ моделей в `data/models/`; `support`, `help` и `review` ничего не скачивают. Индекс SQLite версии 1 пересчитывает изменённые файлы по SHA-256; `--full` пересчитывает весь корпус. `--probe` показывает В1–В8 по документации, К1–К4 по коду, Ф1–Ф4 по FAQ. Корпус: README, `docs/*.md`, `week7/README.md`, Python-код и скрипты запуска; правила агентов и `week7/docs/*` исключены. FAQ имеет отдельный вид `faq`; `help` и `review` его не ищут. Поддержка исключает документацию `week7/*` и не ищет код.

Для своих прогонов задавайте отдельные `--db`, `--port` и `DEVHELP_MODELS_DIR`. `SUPPORT_CRM_COMMAND` заменяет исполняемый файл сервера CRM, `DEVHELP_GIT_COMMAND` — git MCP для проверки сбоев. Ключ LLM в MCP не передаётся. Чужой индекс не затирается; устаревший корпус и другой репозиторий дают предупреждения. `demo/` хранится в git, `data/` и `.env` — вне git.

Прежние команды доступны для запуска:

```bash
./week7/run.sh help "Где вызывается LLM API?"
./week7/run.sh review --base main --head HEAD --out /tmp/review.md
./week7/run.sh git-server --repo /путь/к/проекту
```

## Структура кода

| Файл | Назначение |
| --- | --- |
| `src/settings.py` | Пути, модели, параметры, промпты, вопросы, цены и замеры |
| `src/md_chunks.py`, `src/code_chunks.py` | Чистая нарезка Markdown и кода |
| `src/embedder.py` | Единственная граница fastembed, CPU, локальный кэш |
| `src/docs_index.py`, `src/search.py` | Индекс SQLite, виды, фильтры, поиск и реранк |
| `src/llm.py` | Единственная граница openai: раунды и function calling |
| `src/mcp_client.py` | Клиент MCP v2, stdio, белый список окружения |
| `src/git_server.py` | Отдельный MCP-сервер чтения git |
| `src/citations.py` | Номера выдержек, источники и пометки |
| `src/devhelp.py` | Ассистент разработчика |
| `src/review_report.py`, `src/pr_review.py` | Сбор контекста, проверки и ревью ветки |
| `src/crm_server.py` | Отдельный MCP-сервер CRM: три инструмента чтения |
| `src/support_desk.py` | Старт поддержки, CRM, два поиска, черновик и расход |
| `src/support_web.py` | Starlette/uvicorn, HTTP-проверки, один ответ за раз |
| `src/support_page.html` | Страница оператора без внешних зависимостей |
| `demo/crm.json` | Демо-пользователи и тикеты |
| `run.sh` | uv sync и диспетчер команд |
