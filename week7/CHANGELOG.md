## День 31 — ассистент разработчика (`devhelp`), тег `day31`

- Каталог `week7/` как отдельный продукт: свой `pyproject.toml`, `uv.lock`, `.python-version`, `run.sh`, `.gitignore`, `AGENTS.md` (+ `CLAUDE.md` — символьная ссылка), README, спецификации в `week7/docs/`; ни одного импорта из `src/`.
- RAG по документации проекта: нарезка Markdown по заголовкам (`md_chunks.py`), эмбеддинги `intfloat/multilingual-e5-base` через `fastembed` (ONNX, CPU), реранкер `BAAI/bge-reranker-v2-m3-int8`, индекс SQLite версии 1 (`docs_index.py`), поиск 20 → реранк → 5 (`search.py`).
- Индекс пересчитывает только изменённые файлы по SHA-256; `--full` — с нуля; `--probe` — пробные вопросы В1–В8.
- Свой MCP-сервер `git_server.py` (SDK v2, stdio, только чтение): `git_branch`, `git_status`, `git_log`, `git_diff`; ветку код спрашивает всегда, остальные инструменты модель вызывает сама.
- `llm.py` — единственная граница `openai`: раунды function calling, лог каждого раунда, токены и стоимость; `mcp_client.py` — единственная граница клиента MCP.
- Точка входа: `./week7/run.sh help` — диалог `/help <вопрос>`, `/exit`; `./week7/run.sh help "вопрос"` — один ответ и выход. Ответ со ссылками `[N]`, «Источники» с путём и строкой пишет код.
- Подпись выдержки называет день документа; README и архитектура кода — «текущее состояние»; инструкция «более поздний день точнее раннего».

- Точка входа — GitHub Actions: `.github/workflows/week7-review.yml` (единственный файл недели вне `week7/`) на `pull_request`, кэш моделей и индекса, публикация одного обновляемого комментария через `gh`; локально — `./week7/run.sh review --base main`.
