# AGENTS.md — неделя 7

Этот файл — правила для AI-агентов (Claude Code, Codex и других) при работе в каталоге `week7/`; рядом `CLAUDE.md` — символьная ссылка на него для Claude Code, правится только этот файл. Корневой `AGENTS.md` (процесс, язык, коммиты, `tasks/`, общие правила) действует и здесь. Архитектура TooManyRules (`docs/TooManyRules — архитектура кода.md`) к `week7/` не относится: читать её не нужно, кроме случаев, когда продукт дня разбирает сам TooManyRules.

Язык — русский: README, спецификации, промпты, строки интерфейса и комментарии в коде.

## Что это

Неделя 7 AI Advent Challenge — **серия небольших продуктов, по одному в день**: ассистент разработчика (день 31), AI-ревью PR (день 32), поддержка пользователей (день 33) и дальше по заданиям. Каждый продукт — LLM-ассистент своей роли, собранный из одних деталей: знания (RAG) + контекст ситуации (MCP) + роль (промпт) + точка входа (команда, CI, сервис).

**Демо-продукт всей недели — TooManyRules** из корня этого репозитория: его README и `docs/` — документация, его ветки и PR — материал для ревью, его сбои — материал для поддержки. Продукты недели 7 смотрят на TooManyRules **снаружи** — как на чужой проект: через файлы и git, параметром `--repo`.

Продуктовая ценность для автора реальна (он тимлид мобильной разработки, код-ревью — его узкое место; ревьюер дня 32 — прототип инструмента для его компании), но темп челленджа — день на продукт. Довести продукт до рабочего инструмента — после недели, не в её темпе.

## Главное правило каталога: `week7/` выносится в отдельный репозиторий

- **Ни одного импорта из `src/`** и никакой правки `sys.path` на `src/`. Приёмы TooManyRules переносятся **копированием и упрощением**, не импортом.
- Свои `pyproject.toml`, `uv.lock`, `.python-version`, `.venv`, `.env`, `.gitignore`, `data/`, README, `AGENTS.md` и `CLAUDE.md`, спецификации (`week7/docs/`).
- Запуск — только `./week7/run.sh <команда>`; корневой `run.sh` про `week7/` не знает.
- Проект, с которым работает продукт, — параметр `--repo` (по умолчанию — корень этого репозитория). Код не должен знать, что лежит внутри TooManyRules.
- Проверка: `git subtree split --prefix=week7` даёт рабочий репозиторий; `grep -rn "src\." week7/src` не находит импортов TooManyRules.

## Процесс

Как в корневом `AGENTS.md`: задание в `tasks/` (из `week7/` — `../tasks/`, вне git, текст не копируется) → Claude пишет `week7/docs/День N спецификация.md` → исполнитель реализует → Claude ревьюит → коммит и тег `dayNN` делает автор (**агенты сами не коммитят и не ставят теги без прямого разрешения**). Формат спецификации — тот же, с обязательным разделом «Что сознательно НЕ делаем на этом шаге».

**Ядро растёт по нуждам дня.** Абстракции под будущие дни заранее не пишутся: задание следующего дня неизвестно. Что из модулей дня станет общим — решает день, которому это понадобилось, правкой с записью в его спецификации.

**README** (`week7/README.md`) описывает только текущий день недели 7 плюс запуск и «Структура кода» в самом конце. Корневой `README.md` в дни недели 7 содержит короткую ссылку на `week7/README.md` вместо описания дня.

## Стек

- Python 3.14, **`uv`** (`uv sync`, `uv run`; `uv.lock` коммитится).
- Эмбеддинги и реранкер — **`fastembed`** (ONNX, без `torch`); модели — в `week7/data/models/`, не в кэше Hugging Face автора.
- LLM — **любой OpenAI-совместимый адрес** через `openai` SDK: `LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY` в `week7/.env`; по умолчанию DeepSeek `deepseek-flash`.
- MCP — SDK v2 (`mcp>=2.2,<3`), API v2: `Client(StdioServerParameters(...))`, `MCPServer`. Примеры из интернета на `ClientSession`/`FastMCP` — это v1.
- Лицензии моделей и библиотек проверяются: продукт может пойти в компанию (реранкер Jina v2 отклонён на дне 31 — CC BY-NC).

## Правила кода (перенесены из TooManyRules)

- **Внешний мир — за своим модулем**: одна библиотека — один модуль, где она импортируется (`fastembed`, `openai`, клиентская и серверная части `mcp`, вызов `git`).
- **Своё «про проект и машину» — в `settings.py`** (аналог `presets.py`): пути, модели, числа поиска, промпты, цены, замеры комментариями.
- **Свой MCP-сервер — отдельная программа**: stdout — канал JSON-RPC, логи — stderr со своим префиксом; ожидаемый сбой — `ToolError` (только его текст доходит до клиента); описания инструментов — это промпт.
- **Логи — основной инструмент отладки**: каждый вызов LLM (модель, раунд, `finish_reason`, время, токены, стоимость), MCP и поиска — строкой в stdout с префиксом программы.
- **Код не оценивает качество ответов** и не подсвечивает «лучший» вариант — это суждение автора.
- **Имена модулей** проверяются на совпадение со стандартной библиотекой и установленными пакетами.
- Тестов и линтера нет; проверка — ручной прогон и логи.

## Свои прогоны (для Claude и исполнителя)

- Данные автора (`week7/data/`, `week7/.env`) не трогать: свой индекс — `--db <свой путь>`, свой ключ — в окружении команды.
- Индекс правил TooManyRules (`src/data/rag/`), его данные и кэш моделей Hugging Face автора `week7/` не читает и не пишет.
- Рабочее дерево автора общее: для проверки git-инструментов — своя ветка и своя правка, после прогона вернуть как было; ничего не коммитить.
