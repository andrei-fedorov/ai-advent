# TooManyRules — день 4

Четвёртая вкладка интерфейса (`День 4 — температура`) прогоняет
**один и тот же вопрос** по правилам через DeepSeek API **девять раз**,
чтобы визуально сопоставить эффект параметра `temperature`:

- 3 значения `temperature` — `0`, `0.7`, `1.2` — заданы явно в самом
  API-запросе (не текстовой инструкцией в промпте).
- По 3 повтора на каждое значение, чтобы увидеть не только содержание
  ответа, но и разброс внутри одной температуры (насколько она
  стабильна или, наоборот, даёт расхождения).
- Системный промпт (тот же `SYSTEM_PROMPT` из дня 1) и сам вопрос не
  меняются между всеми 9 вызовами — единственная переменная это
  `temperature`; `max_tokens`/`stop` из дня 2 не задаются.

Все 9 ответов выводятся тремя колонками (по одной на температуру), в
каждой — 3 подписанных блока с номером повтора. Каждый вызов
логируется в stdout (temperature, номер повтора, `finish_reason`,
длина и текст ответа). Какая температура лучше подходит для каких
задач — решает автор вручную, глядя на ответы; код не считает
автоматическую метрику точности/креативности/разнообразия и не
подсвечивает «лучший» вариант.

## Структура репозитория

- `src/` — весь код проекта. На день 1 это единственная точка входа —
  `src/app.py`; сюда же кладутся `requirements.txt` и `.env`.
- `docs/` — спецификации: общая спецификация проекта и ТЗ по дням
  (день 1 — `TooManyRules — День 1 спецификация.md`).
- `prompts/` — промпты, которыми ставились задачи на реализацию (день 1 —
  `day1-prompt.md`).

## Запуск локально

Быстрый способ — скрипт `run.sh` в корне репозитория: он сам создаёт
`.venv` (если его ещё нет) и ставит зависимости, затем запускает
`src/app.py`.

```bash
./run.sh
```

Перед первым запуском всё равно нужно один раз положить API-ключ в
`src/.env` — см. шаг 2 ниже; без него скрипт запустится, но выведет
предупреждение.

### Пошагово вручную

Все команды ниже выполняются из папки `src/` — код и виртуальное окружение
находятся там, а не в корне репозитория.

1. Перейти в `src/` и установить зависимости (Python 3.12+, проверено на 3.14):
   
   ```bash
   cd src
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
   
   Если системный Python старый, свежий ставится одной командой через [uv](https://docs.astral.sh/uv/):
   `uv python install 3.14 --default`.

2. Получить API-ключ DeepSeek на https://platform.deepseek.com
   и положить его в файл `.env` внутри `src/`:
   
   ```bash
   echo 'DEEPSEEK_API_KEY=...' > .env
   ```
   
   `.env` не коммитится в репозиторий (см. `src/.gitignore`).

3. Запустить (из папки `src/`, с активированным `.venv`):
   
   ```bash
   python app.py
   ```
   
   и открыть в браузере http://127.0.0.1:7860

## Как это устроено

- `src/app.py` — точка входа: системный промпт (константа `SYSTEM_PROMPT`) и вызов
  DeepSeek API через официальный SDK `openai` с `base_url` DeepSeek.
- Многоходовый диалог в рамках открытой вкладки — встроенное поведение
  `gr.ChatInterface`.
