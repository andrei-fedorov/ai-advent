# TooManyRules — день 5

Пятая вкладка интерфейса (`День 5 — модель × thinking`) прогоняет
**один и тот же вопрос** по правилам через DeepSeek API на **матрице
2×2** «модель × режим рассуждения», чтобы раздельно увидеть эффект
размера модели и эффект включения `thinking`:

- Модель — `deepseek-v4-flash` или `deepseek-v4-pro`.
- Режим рассуждения — `thinking` `off` или `on`, переключается через
  `extra_body`, отдельно от имени модели.
- Итого 4 вызова (по одному на ячейку матрицы), без повторов —
  сравниваются модель/режим, а не разброс ответов.
- Системный промпт (тот же `SYSTEM_PROMPT` из дня 1) и сам вопрос не
  меняются между всеми 4 вызовами; `temperature`/`top_p`/penalty-параметры
  и `max_tokens`/`stop` не задаются.

Все 4 ответа выводятся подписанными блоками (модель + режим thinking),
в каждом — текст ответа, время ответа, токены (prompt/completion/total)
и оценочная стоимость в долларах (по актуальным ценам DeepSeek за 1M
токенов). Наименьшее значение по каждой из трёх метрик — время,
`total_tokens`, стоимость — подсвечивается зелёным цветом, независимо
по каждой метрике. Каждый вызов логируется в stdout (модель, thinking
on/off, `finish_reason`, время, токены, длина и текст ответа). Качество
ответов код не оценивает и «лучший» вариант не подсвечивает — это
решает автор вручную, глядя на ответы.

## Структура репозитория

- `src/` — весь код проекта; сюда же кладутся `requirements.txt` и `.env`.
- `src/app.py` — точка входа.
- `docs/` — спецификации: общая спецификация проекта и ТЗ по дням
  (день 1 — `TooManyRules — День 1 спецификация.md`).
- `prompts/` — промпты, которыми ставились задачи на реализацию (день 1 —
  `day1-prompt.md`).

## Запуск локально

Быстрый способ — скрипт `run.sh` в корне репозитория: он сам создаёт
`.venv` (если его ещё нет) и ставит зависимости, затем запускает
`src/app.py`.

```bash
./run.sh
```

Перед первым запуском всё равно нужно один раз положить API-ключ в
`src/.env` — см. шаг 2 ниже; без него скрипт запустится, но выведет
предупреждение.

### Пошагово вручную

Все команды ниже выполняются из папки `src/` — код и виртуальное окружение
находятся там, а не в корне репозитория.

1. Перейти в `src/` и установить зависимости (Python 3.12+, проверено на 3.14):
   
   ```bash
   cd src
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
   
   Если системный Python старый, свежий ставится одной командой через [uv](https://docs.astral.sh/uv/):
   `uv python install 3.14 --default`.

2. Получить API-ключ DeepSeek на https://platform.deepseek.com
   и положить его в файл `.env` внутри `src/`:
   
   ```bash
   echo 'DEEPSEEK_API_KEY=...' > .env
   ```
   
   `.env` не коммитится в репозиторий (см. `src/.gitignore`).

3. Запустить (из папки `src/`, с активированным `.venv`):
   
   ```bash
   python app.py
   ```
   
   и открыть в браузере http://127.0.0.1:7860

## Как это устроено

- `src/app.py` — точка входа: системный промпт (константа `SYSTEM_PROMPT`) и вызов
  DeepSeek API через официальный SDK `openai` с `base_url` DeepSeek.
- Многоходовый диалог в рамках открытой вкладки — встроенное поведение
  `gr.ChatInterface`.
