# TooManyRules — день 2

Вторая вкладка интерфейса (`День 2 — формат ответа (A vs B)`) берёт
**один и тот же вопрос** по правилам и отправляет его в DeepSeek API
дважды с разной конфигурацией, чтобы наглядно показать разницу
«свободный ответ vs управляемый формат»:

- **Вариант A** — без ограничений: системный промпт из дня 1, без
  `max_tokens`/`stop`, без требований к формату. Ответ — свободный
  текст произвольной длины.
- **Вариант B** — с ограничениями: тот же вопрос, дополненный
  системный промпт требует строгий JSON
  (`rule_summary`, `details`, `confidence`) и явный маркер завершения
  `###END###`; в запрос явно передаются `max_tokens=150` и
  `stop=["###END###"]`. Ответ — короткий валидный JSON.

Оба вызова логируются в stdout (смотрите терминал, где запущен
`app.py`) — рядом с каждой строкой `Variant A response` /
`Variant B raw` / `Variant B parsed` будет полный текст ответа API.
JSON варианта B дополнительно парсится через `json.loads()`;
результат парсинга и распарсенный объект отображаются в интерфейсе.

## Структура репозитория

- `src/` — весь код проекта. На день 1 это единственная точка входа —
  `src/app.py`; сюда же кладутся `requirements.txt` и `.env`.
- `docs/` — спецификации: общая спецификация проекта и ТЗ по дням
  (день 1 — `TooManyRules — День 1 спецификация.md`).
- `prompts/` — промпты, которыми ставились задачи на реализацию (день 1 —
  `day1-prompt.md`).

## Запуск локально

Все команды ниже выполняются из папки `src/` — код и виртуальное окружение
находятся там, а не в корне репозитория.

1. Перейти в `src/` и установить зависимости (Python 3.12+, проверено на 3.14):
   
   ```bash
   cd src
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
   
   Если системный Python старый, свежий ставится одной командой через [uv](https://docs.astral.sh/uv/):
   `uv python install 3.14 --default`.

2. Получить API-ключ DeepSeek на https://platform.deepseek.com
   и положить его в файл `.env` внутри `src/`:
   
   ```bash
   echo 'DEEPSEEK_API_KEY=...' > .env
   ```
   
   `.env` не коммитится в репозиторий (см. `src/.gitignore`).

3. Запустить (из папки `src/`, с активированным `.venv`):
   
   ```bash
   python app.py
   ```
   
   и открыть в браузере http://127.0.0.1:7860

## Как это устроено

- `src/app.py` — точка входа: системный промпт (константа `SYSTEM_PROMPT`) и вызов
  DeepSeek API через официальный SDK `openai` с `base_url` DeepSeek.
- Многоходовый диалог в рамках открытой вкладки — встроенное поведение
  `gr.ChatInterface`.
