# TooManyRules — день 3

Третья вкладка интерфейса (`День 3 — способы рассуждения`) прогоняет
**один и тот же неоднозначный вопрос** по правилам через DeepSeek API
**четырьмя способами рассуждения**, чтобы визуально сопоставить результаты:

- **Способ 1 — прямой ответ.** Базовый системный промпт из дня 1, без
  дополнительных инструкций про рассуждение.
- **Способ 2 — «решай пошагово».** Тот же промпт, дополненный
  инструкцией: сначала расписать рассуждение по шагам (какие правила
  применимы, в каком порядке разрешаются, есть ли прямое указание или
  это интерпретация), затем дать финальный ответ отдельным абзацем.
- **Способ 3 — модель сама формулирует промпт.** Два последовательных
  вызова API: сначала модель генерирует «идеальный» промпт для разбора
  вопроса, затем этот промпт отправляется отдельным запросом и модель
  отвечает уже на него. Оба вызова видны в stdout-логах.
- **Способ 4 — консилиум экспертов.** Один системный промпт с тремя
  персонами — Rules Lawyer (формальный разбор правил), Game Designer
  (замысел и баланс игры) и Skeptic (противоречия и слабые места), —
  отвечающими последовательно в одном ответе, с итоговым выводом.

Все четыре ответа выводятся рядом, каждый подписан своим способом.
Какой способ точнее — решает автор вручную по бумажной книге правил
(RAG ещё не подключён); код это не вычисляет и не подсвечивает.

## Структура репозитория

- `src/` — весь код проекта. На день 1 это единственная точка входа —
  `src/app.py`; сюда же кладутся `requirements.txt` и `.env`.
- `docs/` — спецификации: общая спецификация проекта и ТЗ по дням
  (день 1 — `TooManyRules — День 1 спецификация.md`).
- `prompts/` — промпты, которыми ставились задачи на реализацию (день 1 —
  `day1-prompt.md`).

## Запуск локально

Быстрый способ — скрипт `run.sh` в корне репозитория: он сам создаёт
`.venv` (если его ещё нет) и ставит зависимости, затем запускает
`src/app.py`.

```bash
./run.sh
```

Перед первым запуском всё равно нужно один раз положить API-ключ в
`src/.env` — см. шаг 2 ниже; без него скрипт запустится, но выведет
предупреждение.

### Пошагово вручную

Все команды ниже выполняются из папки `src/` — код и виртуальное окружение
находятся там, а не в корне репозитория.

1. Перейти в `src/` и установить зависимости (Python 3.12+, проверено на 3.14):
   
   ```bash
   cd src
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
   
   Если системный Python старый, свежий ставится одной командой через [uv](https://docs.astral.sh/uv/):
   `uv python install 3.14 --default`.

2. Получить API-ключ DeepSeek на https://platform.deepseek.com
   и положить его в файл `.env` внутри `src/`:
   
   ```bash
   echo 'DEEPSEEK_API_KEY=...' > .env
   ```
   
   `.env` не коммитится в репозиторий (см. `src/.gitignore`).

3. Запустить (из папки `src/`, с активированным `.venv`):
   
   ```bash
   python app.py
   ```
   
   и открыть в браузере http://127.0.0.1:7860

## Как это устроено

- `src/app.py` — точка входа: системный промпт (константа `SYSTEM_PROMPT`) и вызов
  DeepSeek API через официальный SDK `openai` с `base_url` DeepSeek.
- Многоходовый диалог в рамках открытой вкладки — встроенное поведение
  `gr.ChatInterface`.
